# Pyramid Task Management System (TMS)

This is a premium, full-stack Task Management System built as part of the Full Stack Developer Technical Assessment. It matches the Figma design parameters for layouts, spacing, themes, typography, and interactive components.

---

## 🚀 Tech Stack

### Frontend
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (v4 Directives & Custom CSS Variables)
- **Icons:** Lucide React

### Backend
- **Framework:** NestJS
- **Language:** TypeScript
- **Database:** MongoDB (via Mongoose ODM)
- **Validation:** Class-validator & Class-transformer
- **Authentication:** Passport-JWT

## 🎨 Theme & Color Accent Customization

The system implements a dual-dimension styling customizer:
1. **Theme:** Light vs. Dark modes (using standard Tailwind `.dark` classes).
2. **Color Mode (Accent Colors):** `Amber`, `Blue`, `Pink`, `Rose`, `Emerald`, and `Black` (maps to slate in dark mode).

### Implementation Details
We define custom CSS properties (variables) on `:root` and `.dark` in `globals.css` (e.g., `--accent`, `--accent-hover`, `--accent-light`). These are dynamically controlled in JavaScript by updating class lists on the `document.documentElement` and persisted in `localStorage`. 

In Tailwind, these are mapped in the `@theme` block:
```css
@theme {
  --color-accent: var(--accent);
  --color-accent-hover: var(--accent-hover);
  --color-accent-light: var(--accent-light);
}
```
This enables native styling across all components with classes like `bg-accent`, `text-accent`, and `hover:bg-accent-hover`.

## ⚙️ How to Setup and Run Locally

### Prerequisites
- Node.js (v18+ recommended, tested on v22)
- Local MongoDB running on default port `27017`

### 1. Run the NestJS Backend
The backend server runs on port `8080` and connects to the local MongoDB database at `mongodb://localhost:27017/tms`.

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the NestJS development server:
   ```bash
   npm run start:dev
   ```
   *Note: On startup, the backend automatically seeds the database with team members and 11 tasks matching the exact properties and text in the Figma design if the database is empty.*

### 2. Run the Next.js Frontend
The frontend runs on port `3000` and proxies API requests to `http://localhost:8080/api`.

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the Next.js development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📌 Features & Design Fidelity

1. **Figma Design Integrity:** Colors, borders, headers, layouts, icons, and typography match the design.
2. **Guest Login:** Immediately enters the application as a guest user using a secure JWT payload generated by the NestJS backend.
3. **Task Board View:** Columns for "To Do", "Doing", and "Completed" with lightweight HTML5 drag-and-drop mechanics to seamlessly update task status.
4. **Task List View:** Collapsible status sections and dynamic column visibility toggling matching the Figma "Fields" dropdown.
5. **Task Details Drawer:** Displays sliding overlays from the right side, supporting title/description edits, subtask checkoffs, inline subtask creations, file/link resources, and comments timeline.
6. **Persistence:** Theme (Light/Dark), Accent Color, and View Mode (List/Board) persist on page refreshes.

## 🔍 Intentional Deviations & UX Improvements

- **Login Screen Input:** The Figma login block says *"Enter your email below to login to your account"*, but displays no email input field, only Google and Guest login buttons. To maintain visual fidelity, we matched the buttons layout but added a name input field when clicking "Continue as Guest" to personalize the guest workspace.
- **Project Seeding Control:** Added a "Reset Demo Data" button in the sidebar. This clears MongoDB collections and re-seeds it with the original Figma tasks, making it extremely easy to demonstrate drag-and-drop or edit features multiple times.
- **Drag and Drop:** Implemented using native HTML5 drag-and-drop APIs. This provides smooth reordering and card drag movements without adding heavy external library packages (like react-beautiful-dnd or dnd-kit), improving initial bundle load speeds.
